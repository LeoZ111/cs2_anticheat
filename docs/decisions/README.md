# Entscheidungen

Jede wichtige Entscheidung bekommt eine kurze Datei: `NNNN-thema.md`.
So kann man später nachlesen, **warum** etwas so gebaut wurde.

Aufbau einer Datei:

- **Status:** vorgeschlagen, angenommen oder ersetzt
- **Frage:** Was musste entschieden werden?
- **Entscheidung:** Was wurde gewählt?
- **Warum:** Gründe, auch gegen die Alternativen
- **Folgen:** Was ändert sich dadurch?
